Roundcube Webmail updates fix 12 security flaws

Roundcube has released updates to fix weaknesses in its email software that could expose data or allow unwanted code to run.

Thursday 26 November 2026, 3.57pm

What happened

Roundcube released versions 1.6.22 and 1.7.7 on 23 November 2026. These updates address 12 security flaws in the browser-based email client. The fixes cover how the software handles attachments, displays messages, and connects to mail servers.

The release notes describe flaws that could expose data and allow unauthorised email filter code to run. However, they do not confirm that hackers can take full control of the server or that these bugs are being actively exploited right now. One fix stops the software from passing unsafe file content to a tool used to process images.

Other fixes address how Roundcube displays HTML email. Two flaws let message styling break out of the limits meant to keep it separate from the webmail interface. Another fix stops SVG content from loading external resources, which helps protect privacy by preventing email tracking.

The updates also stop Roundcube from falling back to unencrypted connections when encryption is configured. This matters because a setting that appears to require encryption did not always prevent an unencrypted connection. Administrators are advised to back up their data and patch systems promptly.

Am I affected?

You can check if you are affected by looking at the software your organisation uses for email. If you use Roundcube Webmail, you should check with your IT team to see if they have installed the latest updates.

What to do

  • If you manage Roundcube, update to version 1.6.22 or 1.7.7 immediately.
  • Back up your data before applying the updates.
  • If you are on version 1.6, apply the 1.6.22 update rather than waiting to move to 1.7.
  • Note that only the 1.7 branch will receive future security updates.
