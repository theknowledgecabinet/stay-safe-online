Criminals using flaw to hijack Drupal websites

A serious security flaw in the Drupal website software is being used by criminals to take control of live websites.

Thursday 26 November 2026, 6.10am

What happened

The Drupal security team has confirmed that a critical weakness in its software is being actively exploited. This flaw, known as CVE-2026-132165, allows attackers to gain control of websites that have not been updated with the latest security fixes.

Drupal is a popular tool used to build websites for large organisations, including government bodies and universities. The security team warned that criminals can use a specific file in the software to reinstall the system and take over the site. This has been happening on live websites since at least 19 November 2026.

The US Cybersecurity and Infrastructure Security Agency (CISA) has added this issue to its list of known exploited vulnerabilities. It has ordered federal agencies to fix their systems by 27 November 2026. CISA says these types of flaws are a frequent target for malicious cyber actors.

If you run a website using Drupal, you should update to the latest version immediately. If you cannot update right away, you can block access to a specific file called 'install.php' to help secure your site.

Am I affected?

The sources do not say who is affected. You can check if you are affected by looking at the software used to build your organisation's website.

What to do

  • Check if your organisation uses Drupal and update it to the latest version.
  • If you cannot update immediately, block access to the 'install.php' file in your web server settings.
  • Keep your software up to date to protect against known security flaws.
  • Follow guidance from official security agencies like CISA for best practices.
