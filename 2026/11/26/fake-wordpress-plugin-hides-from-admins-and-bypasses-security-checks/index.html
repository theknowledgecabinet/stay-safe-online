Fake WordPress plugin hides from admins and bypasses security checks

A malicious plugin can let attackers access websites without extra security steps and run harmful code on visitors' devices.

Thursday 26 November 2026, 3.59pm

What happened

Researchers from the Wordfence Threat Intelligence Team found a fake WordPress plugin that hides itself from the website's main control panel. This makes it hard for site owners to spot the problem even when they check their settings.

The plugin creates a backdoor. This is a hidden entry point that lets attackers sign in without completing two-factor authentication (2FA). Two-factor authentication is an extra security step, like a code sent to your phone, that confirms you are who you say you are.

It also runs harmful scripts in the browsers of people visiting the site. These scripts can be used for phishing, which involves fake messages that try to trick you into giving away details. Wordfence said the plugin could also be used for fake update prompts or tracking keystrokes.

Wordfence released detection tools for this specific malware to paid customers on 16 October and to free users on 15 November 2026.

Am I affected?

The sources say this affects website owners who use WordPress. If you run a website, you should check your plugin list against the files on your server. The sources don't say who is affected if you are just a visitor, but you should be careful about clicking links on unfamiliar sites.

What to do

  • Compare the plugins listed in your dashboard with the actual files in your website's folder.
  • Check your public website while signed out to see if any strange scripts are running.
  • If you find the plugin, remove it and change your administrator passwords.
  • Keep two-factor authentication enabled, as it still protects normal logins.
