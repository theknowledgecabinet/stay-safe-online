GL.iNet routers and KVM devices hit by cloud flaw

Hackers used a flaw in GL.iNet's remote management service to install malware on some home routers and remote control devices.

Monday 23 November 2026, 8.34pm

What happened

GL.iNet confirmed on 20 November 2026 that an unauthorised party exploited a vulnerability in its GoodCloud platform. This platform allows users to manage their routers and KVM devices remotely. The company said it has fixed the cloud vulnerability and blocked the access used in the incident.

However, the fix does not remove malware from devices that were already infected. GL.iNet says stable firmware updates containing additional security fixes are scheduled for release on 22 November 2026. The company recommends that customers install the latest security firmware for their specific model, even if they do not see signs of infection.

Security researchers found custom malware on affected devices. This malware included reverse shells, which are tools that allow remote attackers to execute commands on infected devices. Some devices were also found with backdoors that could give attackers ongoing access.

It is not yet clear how many customers were impacted or if information was stolen. GL.iNet is investigating whether computers connected to infected KVM devices may have been compromised. The company has linked to a community-developed tool that can help scan for and remove known malware components.

Am I affected?

The sources do not say who is affected. You should check if you own a GL.iNet router or KVM device. If you do, check the device for signs of infection and install the latest security firmware as recommended by the company.

What to do

  • Check if you own a GL.iNet router or KVM device.
  • Install the latest security firmware for your specific model as soon as it becomes available.
  • Use the community-developed detection tool linked by GL.iNet to scan for malware.
  • If you use a KVM device, check the connected computers for unfamiliar programs or unusual activity.
