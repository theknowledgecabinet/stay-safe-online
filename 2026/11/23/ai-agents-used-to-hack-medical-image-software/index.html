AI agents used to hack medical image software

Amazon says AI tools helped a China-linked group find and exploit a security flaw in a medical imaging tool.

Monday 23 November 2026, 6.06am

What happened

Amazon’s threat intelligence team says it found evidence of a China-linked group using AI agents to attack medical software. The group targeted universities in East Asia, excluding mainland China. The software, called MONAI Label, helps doctors label medical images using AI.

The attackers used AI to find a bug in the software that allowed them to write files to the server. Amazon says this happened in about 11 minutes. The group then used this access to control other devices on the network. Amazon attributes the attack to a Chinese-nexus threat actor with moderate confidence.

The developers of MONAI Label have published an advisory. They rate the bug as critical. It affects versions 0.8.5 and earlier. A fix is available in the next release. The software is open source, meaning anyone can download and use it.

Am I affected?

The sources say the attack targeted universities in East Asia outside mainland China. The sources don't say if UK users are affected. You can check if you use this specific medical software by looking at your organisation's IT reports or contacting your IT support team.

What to do

  • Check if your organisation uses MONAI Label version 0.8.5 or earlier.
  • If you do, update the software to the latest version to get the fix.
  • Ensure your medical software is not accessible to the public internet without strong security controls.
