Microsoft fixes flaw that let attackers steal cloud keys

Microsoft has fixed a security gap in its Azure cloud service that allowed attackers to steal secret codes used to connect different software.

Tuesday 24 November 2026, 6.17am

What happened

Microsoft says it found a problem in a part of its Azure cloud service called API Management. This service helps organisations manage how their different apps talk to each other. The company says it fixed the issue on 19 November 2026.

Norwegian security officials linked this flaw to attacks on energy companies in Norway. They said the attackers tried to steal secret codes, known as credentials, that allow access to sensitive systems. Microsoft confirmed that some of these codes may have been exposed before the fix was put in place.

Microsoft told customers that the fix was applied automatically to their systems. However, the company warned that this does not cancel any codes that might have already been stolen. If an attacker has your codes, they can still use them to try to get into your systems.

Microsoft advised customers to change their secret codes immediately. It also suggested checking their system logs for any signs of unusual activity that might indicate someone else has been logging in.

Am I affected?

The sources say the flaw affects specific versions of Microsoft Azure API Management, specifically the Classic tiers. If you use this service, you should check if your system has received the update. The sources do not say who is affected if you do not use this specific cloud service.

What to do

  • Check if you use Microsoft Azure API Management and contact your IT team or service provider to confirm the fix is installed.
  • Change any secret codes or passwords that were stored in the affected service.
  • Look for unusual login attempts or activity in your system records.
