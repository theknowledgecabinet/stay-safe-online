Microsoft testing fix for Windows 11 Bluetooth audio quality drops

Microsoft is testing a fix for a long-standing issue that lowers audio quality when using Bluetooth headphones with a microphone.

Tuesday 24 November 2026, 8.58pm

What happened

Windows 11 has a known problem where audio quality drops when you use Bluetooth headphones. This happens because the computer switches to a lower-quality mode to handle the microphone. It often occurs when you join a voice chat or use voice typing.

Microsoft is now testing a fix for this. It is available in preview builds for the Beta and Experimental channels. The fix allows newer Bluetooth devices to keep playing high-quality stereo sound even while the microphone is active.

According to Microsoft, this works for devices that support a specific audio standard called LE Audio. It includes headphones, earbuds, and speakers that support 48kHz playback. Users can find the setting in their sound options to ensure the best quality.

Am I affected?

The sources say this affects Windows 11 users with Bluetooth LE Audio devices that support 48kHz playback.

What to do

  • Check if you are in the Windows Insider Beta or Experimental channel to access the preview fix.
  • If you have the fix, go to Settings > System > Sound > Output to select the new high-quality format option.
