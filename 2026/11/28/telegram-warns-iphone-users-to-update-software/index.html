Updates to install

Telegram warns iPhone users to update software

Telegram says iPhone users with older software are being hacked just by visiting websites, so you should check for updates now.

Saturday 28 November 2026, 6.16am

What happened

Telegram CEO Pavel Durov said on 27 November 2026 that iPhone users are being hacked "on a massive scale". He warned that opening a website could be enough to break into a vulnerable device. The company is sending alerts to users running older versions of the operating system.

Durov did not say how many phones were affected or which specific versions triggered the warning. Receiving the alert does not mean Telegram found evidence that your specific phone was hacked. It is a general warning to keep your software up to date.

Attackers can use malicious code on web pages to exploit flaws in older software. This can happen without you downloading a file or clicking a fake login page. The attack can start while the page loads if your phone has the specific weaknesses the code targets.

Apple has released updates to fix these security issues. You do not need to follow download links from messages or ads. Instead, you should use the built-in settings on your phone to install the latest version available for your model.

Am I affected?

The sources do not say exactly which iPhone models or iOS versions are affected. You can check if you are affected by going to your iPhone's Settings, then General, and then Software Update. If an update is available, you are likely running an older version.

What to do

  • Go to Settings, then General, and then Software Update on your iPhone.
  • Install the latest update offered for your specific phone model.
  • Turn on Automatic Updates so future fixes install overnight while charging.
  • Back up your phone and connect to Wi-Fi before installing the update.
