Hackers use stolen AI chat data to search cloud storage

Security firm Dragos says criminals used access keys stolen from AI prompts to look for passwords in cloud services.

Saturday 28 November 2026, 3.51pm

What happened

Security firm Dragos says it traced hacker activity to test credentials it had placed in AI prompts. The attackers used these stolen keys to search Amazon Web Services (AWS) cloud storage and secret management tools. They looked for passwords, API tokens, and application settings. Some keys were tested within hours of being submitted.

Dragos sent nearly two million prompts containing unique links and decoy credentials between July and November 2026. It found evidence of exposure at three AI hosting providers. This does not mean two million prompts were stolen. It shows that data can be taken when a provider first receives the traffic.

The attackers also tried to create new user accounts and enable AI models. Dragos reported these as attempts, not confirmed changes. The activity did not require a software flaw; the attackers simply presented valid credentials. Encryption protects data while it travels but does not hide it from the provider processing it.

Malwarebytes noted that attackers obtained credentials even from some prompts the hosting provider rejected. OpenRouter, an AI router, said the findings did not show a breach of its own systems. It removed three providers and withdrew zero-data-retention eligibility from 125 endpoints.

Am I affected?

The sources do not say who is affected.

What to do

  • Do not paste passwords or access keys into AI chat prompts.
  • If you find a live key in a prompt, deactivate it promptly.
  • Review your cloud activity logs for unexpected use or new users.
  • Restrict sensitive work to approved providers only.
