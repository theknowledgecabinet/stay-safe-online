Fake job tests used to infect Windows developers

Criminals are using fake coding tests to spread malware to Windows developers, putting their work and personal data at risk.

Saturday 28 November 2026, 3.47pm

What happened

Security researchers have found 13 malicious software packages designed to trick Windows developers. These packages look like normal tools used to build applications, but they contain hidden code. The attackers disguised the malware as a "take-home" job assessment, a common test used in hiring processes.

According to Socket, a security firm, the fake projects instruct candidates to build and run the code on their own computers. When a developer does this, the hidden code downloads files from the internet. It then installs software that can steal saved passwords and give criminals remote access to the machine.

The researchers say the stolen data could include source code, security keys, and browser logins. Because the malware runs on the developer's own computer, it can hide better than attacks coming from outside. This makes it harder for security systems to spot the intrusion.

Socket says the most recent example they found was a GitHub repository created on 4 November 2026. They could not find any official job posts or emails linked to the campaign. This suggests the lures may have been sent through other, unverified channels.

Am I affected?

The sources say this targets Windows developers who receive coding assessments. If you are not a software developer, you are likely not directly targeted by this specific scam. However, if you receive an unexpected job test or ask you to download and run code, treat it as suspicious.

What to do

  • Do not build or run code from job assessments you did not request or verify.
  • Check for unfamiliar software packages or scripts before installing anything.
  • Only open unknown projects in a separate, isolated computer environment with no personal data.
  • Verify any recruiter through official company channels before sharing your details.
