Ruby programming language fixes security flaw

A fix is available for a weakness in Ruby that could allow attackers to disrupt services, though experts say it is hard to exploit.

Sunday 22 November 2026, 6.48pm

What happened

The Ruby programming language has released updates to fix seven security weaknesses. The most serious issue, called Ruby2Shell, involves a mistake in how the software handles text. This error could potentially let an attacker run commands on a server.

According to SecurityWeek, the flaw occurs when changing the capitalisation of letters in certain text formats. For example, turning a specific German character into uppercase might cause the software to write data in the wrong place in memory. This could corrupt the system.

Experts from WatchTowr told SecurityWeek that successfully using this flaw to take over a system is very difficult. They said attackers would need very specific conditions to be met. It is more likely that bad requests would just stop the service from working, rather than giving hackers full control.

Patches for all seven issues are included in Ruby versions 4.0.10, 3.4.13, or 3.3.14. The developers advise users to apply these fixes as soon as possible to stay safe.

Am I affected?

This affects websites and apps built with the Ruby programming language. If you use a service that runs on Ruby, such as certain social media platforms or project management tools, your provider needs to update their software. The sources do not list every specific website that uses Ruby, so you cannot easily check this yourself.

What to do

  • If you run a website or app that uses Ruby, update it to version 4.0.10, 3.4.13, or 3.3.14 immediately.
  • If you are a regular user, check if the services you use have posted updates or maintenance notices.
  • Keep your devices and apps updated with the latest security patches.
