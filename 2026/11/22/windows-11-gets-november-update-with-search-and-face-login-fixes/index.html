Windows 11 gets November update with search and face login fixes

Microsoft has released an optional update for Windows 11 that improves search speed and helps facial recognition work in dark rooms.

Sunday 22 November 2026, 6.48pm

What happened

Microsoft has released a new optional update for Windows 11. This update, known as KB5132057, is available for versions 25H2 and 26H2. It includes 28 changes and fixes to make the system run better.

One key change is to Windows Search. The search box now has a cleaner design and removes promotional content from web results. This makes the tool more efficient and easier to use. You can also complete tasks like turning on dark mode directly from the search bar.

The update also improves Windows Hello, the facial recognition feature. If you enable a specific setting, your computer can now recognise your face in dark rooms. This helps you sign in more easily when the lights are off.

Microsoft says this is the final non-security preview update for the year. Normal monthly updates will resume in January. The company also warned that some devices might restart one extra time during installation to update security certificates.

Am I affected?

This update is for people using Windows 11 versions 25H2 or 26H2. It is an optional preview update, so it will not install automatically unless you have chosen to get updates as soon as they are available. You can check if you have the update by looking at your Windows Update settings.

What to do

  • Open Windows Settings and click on Windows Update.
  • Click 'Check for Updates' to see if the update is available.
  • If you want the new features, click 'Download and install'.
  • Allow your computer to restart if prompted to finish the installation.
