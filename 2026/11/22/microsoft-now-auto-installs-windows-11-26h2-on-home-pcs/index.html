Updates to install

Microsoft now auto-installs Windows 11 26H2 on home PCs

Microsoft is automatically upgrading eligible personal computers to the latest Windows 11 version, so you may see the update without checking for it yourself.

Sunday 22 November 2026, 6.47pm

What happened

Microsoft has started automatically installing Windows 11 26H2 on devices that are not managed by an IT department. This includes personal computers and business devices that do not have central IT control.

The update is rolling out to devices currently running Windows 11 24H2 or 25H2. Microsoft said this step makes it easier for users to get the latest version without manual intervention.

You can still choose to install the update yourself. To do this, go to Settings, then Windows Update, and select 'Check for Windows updates'. You can also turn on the option to get the latest updates as soon as they are available.

Microsoft confirmed that this month's security update for newer Windows 11 versions is causing some issues with installing or launching Office and other apps. The company is aware of these problems.

Am I affected?

You are affected if you have a personal computer running Windows 11 24H2 or 25H2.

What to do

  • Check your Windows Update settings to see if automatic updates are enabled.
  • If you prefer to control when updates happen, you can manually check for updates in Settings.
