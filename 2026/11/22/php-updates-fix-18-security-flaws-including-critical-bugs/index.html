PHP updates fix 18 security flaws, including critical bugs

The PHP team has released updates to fix 18 security issues, some of which could let attackers control servers.

Sunday 22 November 2026, 6.45pm

What happened

The team that develops PHP, a popular tool for building websites, has released new security updates. These updates fix 18 different flaws in the software.

Some of these flaws are described as critical. This means an attacker could potentially run code on a server without needing to log in first. This is known as remote code execution.

According to the report, the updates were released on Thursday, 19 November. They are available for all supported versions of PHP, including the latest releases.

The updates are designed to close these gaps before they can be used to harm websites or servers.

Am I affected?

This affects websites and servers that use PHP. If you run a website, you need to check if your server is using an older version. The sources do not list specific website names, so you must check your own hosting provider or server settings.

What to do

  • Check with your web hosting provider to see if they have installed the new PHP updates.
  • If you manage your own server, update PHP to the latest supported version listed in the report.
  • Keep your software up to date to protect against known security flaws.
