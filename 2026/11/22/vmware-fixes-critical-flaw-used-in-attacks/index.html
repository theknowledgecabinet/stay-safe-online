VMware fixes critical flaw used in attacks

Broadcom has released an urgent update to fix a security hole in VMware vCenter that hackers have been using since September.

Sunday 22 November 2026, 8.08pm

What happened

Broadcom has released security updates to fix a critical VMware vCenter Server authentication bypass vulnerability that Chinese-linked hackers have exploited in zero-day attacks since September 2026. This vulnerability affects the VMware Directory Service in vCenter Server, a management platform organisations use to manage VMware virtualised environments.

According to reports from security researchers at Google, a hacking group linked to China has been using this flaw since early September 2026. The group, known as Armory Castle, used the bug to bypass authentication and gain unauthorised access. They then moved deeper into the networks to steal sensitive data.

Broadcom says the fix is available now and considers this an emergency update. The company advises organisations to install the patch as soon as possible. There are no official workarounds, though using network restrictions and firewalls can help reduce the risk while you wait for the update.

Am I affected?

The sources say this affects organisations running VMware vCenter, SDDC Manager, or VMware Tools for Windows prior to the fixed versions listed in the advisory. This includes systems deployed standalone or as part of larger VMware platforms. If you are a home user, you are unlikely to use this specific enterprise software, but you should check if your workplace or school uses it.

What to do

  • If you work for an organisation that uses VMware, tell your IT team about this update immediately.
  • Check your organisation's security notices to see if they have already installed the patch.
  • Keep your personal devices updated with the latest security fixes from your operating system provider.
