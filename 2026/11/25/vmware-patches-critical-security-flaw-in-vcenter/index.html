VMware patches critical security flaw in vCenter

Broadcom has released updates to fix a serious bug in VMware software that could let attackers bypass login checks.

Wednesday 25 November 2026, 4.03pm

What happened

Broadcom has shipped patches to fix 23 security flaws in its VMware products. This includes a critical bug in vCenter, a tool used to manage virtual machines. The flaw is rated 9.8 out of 10, which is very high. It sits in a part of the software called the VMware Directory Service, or vmdir.

The bug allows a bad actor to bypass authentication. Authentication is the process of proving who you are, usually with a password. If this flaw is used, an attacker could get into the system without proper permission.

The update covers several VMware tools, including ESX, Workstation, Fusion, and Avi Load Balancer. Broadcom has made the fixes available to address these issues. Users of these products need to install the new patches to close the gap.

Am I affected?

The sources do not say who is affected. You should check if you use VMware vCenter, ESX, Workstation, or Fusion. Look for security notices from Broadcom or your IT provider to see if you need to update.

What to do

  • Check if you use VMware vCenter, ESX, Workstation, or Fusion.
  • Install the latest patches from Broadcom to fix the security flaws.
  • Ask your IT team to confirm your systems are up to date.
