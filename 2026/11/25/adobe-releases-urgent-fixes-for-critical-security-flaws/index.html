Adobe releases urgent fixes for critical security flaws

Adobe has released updates to fix serious weaknesses in its software that could allow attackers to run harmful code on servers.

Wednesday 25 November 2026, 4.00pm

What happened

Adobe published security updates on 24 November 2026. These updates fix critical vulnerabilities in Adobe Experience Manager and Adobe Campaign Classic. A vulnerability is a weakness in software that a hacker can use to break in.

The flaws could let attackers run malicious code on affected servers. They could also allow attackers to gain permissions they should not have or bypass security checks. Adobe said it was not aware of any attacks using these flaws when it published the updates.

The updates are rated as critical, with a severity score of 9.9 out of 10. This high score indicates a serious risk. However, Adobe noted that no active exploitation was reported at the time of the release.

For businesses using these products, it is essential to install the latest updates. Adobe has provided specific version numbers and hotfixes for administrators to check. This ensures the software is protected against these specific weaknesses.

Am I affected?

The sources do not say who is affected. These flaws affect specific versions of Adobe Experience Manager and Adobe Campaign Classic used by organisations. You can check if you are affected by looking at the software versions installed on your work devices or by checking notices from your IT team.

What to do

  • If you use Adobe Experience Manager or Campaign Classic at work, tell your IT team about these updates.
  • Ask your IT team to check which version of the software is installed.
  • Ensure the latest security updates are installed as soon as possible.
  • Keep your other software up to date to stay safe online.
