Drupal websites being targeted by new security flaw

A security hole in the popular website software Drupal is being used in attacks, so site owners need to update their systems now.

Wednesday 25 November 2026, 4.01pm

What happened

Security agency CISA and Drupal developers say a flaw in the software is being exploited in the wild. The issue, named Fail2Install, allows an attacker to take over a website or run harmful code. It was fixed on 18 November, but attacks started shortly after that date.

The problem affects the part of Drupal used to set up a new site. An attacker can use this to reinstall the software and hijack the website. Drupal has rated the vulnerability as 'highly critical' because of the attacks.

Patches are available in Drupal versions 11.4.13, 11.3.22 and 10.6.22. Older versions that are no longer supported will not get a fix. CISA added the flaw to its list of known exploited vulnerabilities on 24 November.

It is not clear how many websites are affected. There is no public information on specific attacks. This is the third time a Drupal flaw has been exploited in the wild this year.

Am I affected?

The sources do not say who is affected. If you run a website using Drupal, check your version number against the list of fixed versions. If you are a visitor, look for official notices from the specific websites you use.

What to do

  • If you manage a Drupal site, update to version 11.4.13, 11.3.22 or 10.6.22 immediately.
  • Secure the Drupal installer after you have finished setting up your site.
  • Ensure your web server cannot write to or change permissions on the settings.php file, as this mitigates some exploit paths.
  • Keep your software up to date to protect against future flaws.
