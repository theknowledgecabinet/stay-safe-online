Microsoft fixes security flaw in Azure API Management

Norway's security agency says an actor was actively looking for business secrets in a flaw in Microsoft's cloud service.

Wednesday 25 November 2026, 4.05pm

What happened

Norway's National Security Authority (NSM) has disclosed a security vulnerability in Microsoft's Azure API Management service. This service helps businesses manage how their software talks to each other.

The NSM said an unknown actor was actively looking for access tokens and secrets in this system. Access tokens are digital keys that allow programs to connect to services securely. The agency noted that several Norwegian businesses, including energy companies Equinor and Skagerak Energi, were affected.

The NSM stated it is still uncertain how the actor gained access.

Am I affected?

The sources say this affected multiple businesses in Norway, including energy companies. It does not say if individual UK consumers are affected. If you use Microsoft Azure for work, check your company's IT notices for updates.

What to do

  • If you use Microsoft Azure, ask your IT team to install the latest security updates.
  • Keep your passwords and access tokens secure and change them if you suspect they may be compromised.
  • Watch for official notices from Microsoft or your employer regarding this specific issue.
