Windows update may stop printing for some business users

Microsoft says a recent update can cause printing errors on some Windows 11 computers, but a fix is not yet available.

Wednesday 25 November 2026, 4.07pm

What happened

Microsoft has confirmed that some users are experiencing printing problems after installing a specific Windows update. This issue affects only computers running Windows 11 version 24H2 or later. The problem occurs when the update is installed alongside a security tool called Forcepoint DLP Endpoint Agent.

According to Microsoft, the print option may appear greyed out or show errors. This happens because the Print Spooler service, which manages print jobs, fails to start. Microsoft says this issue is linked to a compatibility problem between the update and the Forcepoint software.

A permanent fix is not yet available. However, Forcepoint has shared a temporary workaround for its customers. This can be found in a support document on the Forcepoint portal, which requires a sign-in to access.

These issues should not affect systems with the standard November 2026 Patch Tuesday security updates, only those that have installed the hotpatch updates pushed through Microsoft's Windows Autopatch, a cloud-based enterprise service designed to automate Windows and Microsoft 365 updates.

Am I affected?

The sources say this affects only systems running Windows 11 24H2 or later that use the Forcepoint DLP Endpoint Agent. It also only affects computers using the Windows Autopatch service, which is a cloud-based enterprise service available to customers with a Windows 10/11 Enterprise E3 license or greater.

What to do
