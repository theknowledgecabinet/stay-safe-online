Microsoft confirms login problems after November Windows updates

New security updates for Windows are causing some users to fail to sign in to certain apps and devices.

Wednesday 25 November 2026, 4.01pm

What happened

Microsoft has confirmed that some customers are experiencing authentication issues after installing the November security updates. These updates were designed to fix a high-severity security flaw in the Windows Remote Procedure Call Runtime. This flaw allowed attackers to run code on unpatched systems without user interaction.

The fix improves how Windows handles a type of login called NTLM. It makes these logins more secure by adding extra checks. However, Microsoft says this change can cause problems if third-party apps or devices do not handle the new security rules correctly. This includes some single sign-on solutions and authentication proxy servers.

Microsoft has not released a permanent fix for these login failures yet. The company advises users to check if their affected software or device supports a different, more secure login method called Kerberos. If it does not, users should contact the vendor for an update that works with the new Windows security requirements.

As a temporary workaround, Microsoft suggests changing a specific setting in the Windows registry. This allows older, less secure logins to work again. However, the company warns this is only a short-term solution and may be removed in future updates.

Am I affected?

The sources say this affects some third-party apps and devices, including authentication proxy servers and single sign-on solutions, that use NTLM authentication. You may be affected if you cannot sign in to a specific app or device after updating Windows. Microsoft says affected devices show specific error messages in their logs, such as 'Not Found' values in the Target Machine fields.

What to do

  • Check if your affected app or device supports Kerberos authentication, which is a more secure login method.
  • Contact the vendor of the affected software or device to ask for an update that complies with the new NTLM protocol requirements.
  • If you are a technical user, Microsoft advises setting a specific registry value as a temporary workaround, but note this is not a long-term fix.
