Microsoft fixes blank screen bug blocking Office apps

A recent update has fixed a problem that stopped some people from opening Word, Excel, and Outlook.

Wednesday 25 November 2026, 4.00pm

What happened

Microsoft has fixed a bug that prevented some users from accessing their Office applications. The issue caused a blank white box to appear on the screen. This box had no text or buttons and could not be closed.

According to Microsoft, this stopped people from using Outlook, Word, Excel, PowerPoint, OneNote, and Access. One user reported installing three separate versions of 365 and launching applications in safe mode without success.

The company confirmed the fix is now available in Microsoft 365 Apps Version 2611 (Build 16.0.20625.20142), released last week. Customers who cannot update because of this bug can upgrade to the latest version from the command line.

This is the latest in a series of issues affecting Microsoft 365 users this year. Earlier bugs included problems with copying and pasting in Excel and errors that removed older versions of Office from some systems.

Am I affected?

The sources say the bug affected customers who saw a blank dialog box when opening Office apps. If you could not open Word, Excel, or Outlook due to a white screen with no buttons, you were likely affected.

What to do

  • Save your work and close all Office applications.
  • Open an elevated command prompt.
  • Run the command "%programfiles%\Common Files\Microsoft Shared\ClickToRun\officec2rclient.exe" /update user updatetoversion=16.0.20625.20142.
