Fix for Ghostscript flaw that lets files run commands

A security fix is available for a flaw in Ghostscript that could let malicious files run commands on servers.

Wednesday 25 November 2026, 4.07pm

What happened

Ghostscript is a program that many web servers use to convert files like PDFs and images into other formats. It often runs in the background when you upload a file to a website.

Security firm pwn.ai showed that a specific type of file could escape the program's built-in safety checks. This allowed the file to run commands on the server that was processing it.

The flaw has now been patched. This means the makers have released a fix to stop this from happening.

If you run a website or server that uses Ghostscript, you should update the software to the latest version to protect it.

Am I affected?

The sources do not say who is affected. You can check if you are affected by looking at the software versions on any servers you manage or by checking for security updates from your service provider.

What to do

  • Check if any servers you use run Ghostscript.
  • Update Ghostscript to the latest version to install the fix.
  • Keep your software up to date to protect against similar issues.
