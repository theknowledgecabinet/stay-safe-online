Fake Minecraft add-on steals login details

A fake Minecraft add-on is stealing player login details and installing hidden software on Windows computers.

Wednesday 25 November 2026, 3.58pm

What happened

Security researchers at SonicWall have identified a fake file called Farmutils-Loader.jar. It looks like a normal add-on for the game Minecraft, but it is actually malware. When a player opens the file, it steals their active login token. This token allows someone else to use the player's Minecraft services for up to 24 hours.

The file also downloads a hidden program called an infostealer. This tool is designed to steal other information from the computer. It hides itself inside what looks like a normal picture file. The malware can start just by double-clicking the file, even if the game is not running.

SonicWall says this file is part of a malware family called SilentNet. They have seen more than 1,200 samples of this family in the wild. The researchers could not confirm exactly what the second stage of the malware steals, as they did not recover the full file. However, it is designed to gather logs and data from the computer.

Am I affected?

The sources do not say who is affected. You should also check your Minecraft account for any unusual activity or login alerts.

What to do

  • Disconnect the affected Windows device from the internet immediately.
  • Run a full security scan on the computer using your antivirus software.
  • Review your account activity from a clean, safe device.
  • Only download Minecraft add-ons from official project pages or trusted platforms.
