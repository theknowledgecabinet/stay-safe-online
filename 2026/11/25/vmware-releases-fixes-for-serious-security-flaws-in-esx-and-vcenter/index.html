VMware releases fixes for serious security flaws in ESX and vCenter

Broadcom has released updates to fix 23 security weaknesses in VMware software, including critical issues that could allow attackers to run harmful code.

Wednesday 25 November 2026, 6.17am

What happened

Broadcom announced on Tuesday that it has released patches for 23 vulnerabilities across several VMware products. These fixes address serious flaws in ESX and vCenter, which are tools used to manage virtual computers.

The vCenter updates fix seven bugs, including a critical issue that could let an attacker bypass security checks. The ESX updates fix seven other issues, including three critical weaknesses that could allow code to be executed on the main system. Broadcom explained that on some products, this could lead to code execution on the machine where the software is installed.

According to Broadcom, some of these issues were already fixed in a vCenter update released last week. Customers who installed that specific version do not need to update again. However, users of vCenter 9.1.x, ESX, VMware Tools, Workstation, Fusion, and Avi Load Balancer need to install the new updates.

Broadcom did not say if these flaws are currently being used by criminals. The company noted that it does not always warn about active exploitation in its public notices.

Am I affected?

The sources do not say who is affected. You can check if you are affected by looking at the software you use for managing virtual machines or contacting your IT provider to see if they have applied the latest VMware updates.

What to do

  • Check if you use VMware ESX, vCenter, Workstation, or Fusion.
  • If you use these tools, install the latest updates from Broadcom.
  • If you use vCenter version 8.0 U3m, you may not need to update again, but check your specific version.
