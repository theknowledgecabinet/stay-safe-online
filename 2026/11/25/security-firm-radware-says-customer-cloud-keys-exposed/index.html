Security firm Radware says customer cloud keys exposed

A cybersecurity company admits attackers accessed some customer details and cloud keys through a mistake in its internal system.

Wednesday 25 November 2026, 6.16am

What happened

Radware, a company that helps protect websites from attacks, says it found a security problem on 19 November 2026. Attackers got into an internal tool that was accidentally left open to the public internet. This tool is called a Cloud WAF management API, which is a secure door for managing website protection settings.

Radware says the attackers could see some customer contact details. For a smaller group of customers, they also accessed keys used to send log files to cloud storage. These keys are like passwords that allow specific programs to talk to cloud services like Amazon Web Services or Microsoft Azure.

The company says it blocked the originating IP address and access to the internal management API. It also revoked and replaced all internal account credentials after detecting the breach on Thursday, ten hours after the initial unauthorized API access. It also says the main protection services for customers continued to work without interruption. Radware is still checking if the stolen keys were actually used to access any data.

The firm has asked affected customers to change their cloud storage keys immediately. It also advised them to check their cloud accounts for any signs of unusual activity since mid-November.

Am I affected?

The sources say this affects customers of Radware who use its Cloud WAF services. Specifically, those who set up log exports to their own cloud storage (like AWS S3 or Azure Blob Storage) are at risk. If you do not use Radware's specific cloud protection tools, you are likely not affected, but you should check your email for any official notices from the company.

What to do

  • Check if you use Radware's Cloud WAF services for your business or website.
  • If you do, change your cloud storage access keys (such as AWS S3 or Azure keys) immediately.
  • Look through your cloud storage logs for any access from unfamiliar IP addresses since 19 November 2026.
  • Keep your other online accounts secure by using strong, unique passwords and two-factor authentication.
