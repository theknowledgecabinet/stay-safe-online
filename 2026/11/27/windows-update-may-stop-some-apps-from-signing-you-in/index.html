Windows update may stop some apps from signing you in

Microsoft says a recent security update can cause login problems for certain third-party apps, but a fix is available.

Friday 27 November 2026, 3.58pm

What happened

Microsoft has confirmed that the November 2026 Windows security updates can cause sign-in failures. This affects some third-party apps and devices that use a specific type of login called NTLM authentication. The issue appeared after teams installed the November 10 update or later versions that include the same changes.

The update helps fix a security flaw that could let an attacker run code on your computer. It does this by requiring a digital signature, which acts like a seal to prove the login message has not been changed. However, some older apps or tools do not handle this new requirement correctly. As a result, Windows may reject the sign-in even if you have typed the correct password.

Microsoft says the problem does not affect the newer Kerberos authentication method. This means you might see one app fail to log in while other services using the same account continue to work. The company has documented a temporary workaround for administrators, but the longer-term fix is to apply an update from the app's maker or switch to Kerberos if possible.

Am I affected?

The sources say the issue affects third-party apps and devices that use NTLM authentication. You may notice this if a specific app stops letting you log in after a Windows update, while other apps work fine. The sources don't say who is affected.

What to do

  • If a specific app stops working, check if the app maker has released an update.
  • Do not try to change system settings yourself unless you are a technical expert, as this can reduce your security.
