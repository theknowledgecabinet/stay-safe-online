Microsoft fixes emergency crash bug in Windows Server 2025

Microsoft has released a quick fix for a problem that caused some business servers to stop working unexpectedly.

Friday 27 November 2026, 3.57pm

What happened

Microsoft has released an emergency update to fix crashes on Windows Server 2025. This happened after some servers installed a security update earlier this month. The problem caused the computers to stop working when a specific type of network route expired.

This is not a security fix, but a repair for a technical error. Microsoft says the update will download and install automatically. You do not need to restart your computer for it to work. It is rolling out to affected devices through Windows Update.

The same security update also caused other issues for some Windows 11 users. These included problems with printing and launching certain applications. Microsoft is aware of these separate issues as well.

Am I affected?

The sources say this affects a limited number of Windows Server 2025 devices that use specific network settings. The sources do not state whether home users are affected.

What to do

  • If you manage a Windows Server, check your Windows Update logs to see if the emergency update has installed.
  • Keep your devices up to date to ensure you get the latest fixes automatically.
