Dell fixes critical flaw in network switch software

Dell has released a fix for a serious security weakness in its Enterprise SONiC software that could allow attackers to run commands on network switches.

Friday 27 November 2026, 4.00pm

What happened

Dell Technologies has patched a critical flaw in its Enterprise SONiC Distribution software. The issue, tracked as CVE-2026-103782, allows a remote attacker with limited privileges to run commands of their choice on an affected network switch. It can also expose files and directories the attacker is not authorised to access.

The vulnerability affects software versions before 4.6.1. Dell disclosed the issue on 19 November 2026 and assigned it a CVSS score of 9.9 out of 10. The advisory describes the possible impact of an attack but does not say that the flaw has been exploited. The National Vulnerability Database classifies the flaw as argument injection, which happens when software does not properly handle input.

Dell lists several PowerSwitch platforms in the advisory, including the E3200-ON series, N3200-ON, S3248T-ON, and S5248F-ON. Administrators should check the installed SONiC version on each switch rather than rely on the hardware model alone. Dell notes that its affected-products table may not cover every supported version and could change as more information becomes available.

Dell recommends upgrading affected systems to version 4.6.1. The Dell security advisory DSA-2026-451 links to the update and points customers to Dell My Account for downloads. Before upgrading, back up each switch configuration and plan how to restore service if the update fails. Afterward, confirm the installed version and check that the switch is passing expected traffic.

Am I affected?

The sources say this affects Dell Enterprise SONiC Distribution software versions prior to 4.6.1. It specifically lists PowerSwitch platforms such as the E3200-ON series, N3200-ON, S3248T-ON, and S5248F-ON. You should check the installed SONiC version on your switches to see if you are affected.

What to do

  • Check the installed SONiC version on your network switches to see if it is before 4.6.1.
  • Upgrade affected systems to version 4.6.1 using the update linked in Dell security advisory DSA-2026-451.
  • Back up each switch configuration before upgrading and plan how to restore service if the update fails.
  • If the update has to wait, limit management access to trusted networks and review which accounts can manage the switches.
