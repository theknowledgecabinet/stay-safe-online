SolarWinds fixes critical flaws in Serv-U server software

SolarWinds has released an update for its Serv-U software to fix serious security gaps that could let attackers take full control of servers.

Friday 27 November 2026, 3.58pm

What happened

SolarWinds released version 2026.4 of its Serv-U software on 24 November 2026. This update fixes 18 security flaws, nine of which are rated as critical. Two of these critical flaws could allow an attacker to gain 'root access' on Linux servers. Root access is the highest level of control on a computer, letting an attacker read or change protected files and alter system settings.

The update also fixes a high-severity flaw that affects only Windows installations. This flaw, known as command injection, could let an attacker run unwanted commands on the server. SolarWinds says the risk from the critical flaws is lower on Windows, but the Windows-only command injection risk remains.

The company credited the Intigriti Bug Bounty Program for reporting the nine critical flaws. The release notes do not say that these specific flaws are currently being used in attacks. However, the update also stops the software from writing multi-factor authentication codes to its logs, which improves account security.

Administrators are advised to install the update as soon as possible. They should start with servers that are connected to the internet and run Linux. Windows servers also need the update to close the command injection gap.

Am I affected?

The flaws affect SolarWinds Serv-U installations, specifically on Linux and Windows servers. You can check if you are affected by looking at the software your organisation uses or checking with your IT team if they run SolarWinds Serv-U.

What to do

  • If you manage servers, update SolarWinds Serv-U to version 2026.4.
  • Back up your configuration before installing the update, as recommended by SolarWinds.
  • Check your server logs for any unexpected file activity or administrator changes after updating.
